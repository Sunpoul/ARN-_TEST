# Агентство развития Норильска

Веб-версия главной страницы из фрейма Figma `2275:8912`. Откройте `index.html` в браузере или запустите из корня проекта локальный сервер.

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory arn-site
```

- `scroll-motion.js` запускает прелоадер и анимацию первого экрана. ScrollTrigger отвечает за появление блоков, параллакс и движение бегущих строк. ScrollSmoother сглаживает прокрутку на десктопе. Библиотеки хранятся в `vendor/`.
- `site.js` индексирует содержимое страницы для поиска, переключает фильтры, направление формы, хронологию и галерею. Поиск открывается кнопкой в шапке или клавишей `/`.
- Проектные фотопревью работают при наведении и фокусе. На сенсорном экране фотографии видны как миниатюры. Доступна системная настройка уменьшения движения.
- Форма идеи подготавливает письмо для почтового приложения. Бэкенд отправки не подключён.

Большинство изображений экспортированы из Figma. Для дополнительных превью использованы [фото конкурса «Новые имена»](https://24rus.ru/news/society/229964.html) и [фото маршрута Discover Taimyr](https://discover-taimyr.ru/tours/Medvejka_i_gora_Obriv).
